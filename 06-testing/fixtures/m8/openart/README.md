# OpenArt Offline Fixtures

These fixtures support repository-only adapter tests. They never authorise or perform an OpenArt call.

Recorded fixtures contain only facts proven by the approved OpenArt integration spike report and incorporated by the external M8 design revision 1.1. Proven historical history/resource IDs are retained as evidence and are explicitly historical and non-callable. Workspace IDs, project IDs, endpoints, credentials, tokens, sessions, cookies, and live configuration are prohibited.

Synthetic fixtures use inert `SYNTHETIC-` identifiers and represent designed failure/status cases, not observed provider behaviour.
