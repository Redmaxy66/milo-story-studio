# M8 Storyboard Specification

**Version:** 1.0
**Format:** text specification and diagrams only in Phase 3

Stable IDs are `<sceneId>-SH##` and `<shotId>-PN##`; order is unique, contiguous, and immutable within a version. Every scene records sequence intent and a visual continuity bible. Every shot/panel records coverage, composition, placement, geography, screen direction, camera movement, action/dialogue timing, transition, continuity, description, and a provider-neutral prompt.

The Storyboard Creator reads the whole source and Film Director brief, preserves the 180-degree rule and source dialogue, and uses the minimum sufficient panels with any below-default count explained. Human approval checks complete eight-scene coverage, editability, agency, story preservation, and reference readiness. No provider-produced storyboard image is permitted in Phase 3.
